## 核心功能特性

### 1. 路径规范化
- 自动处理多余的斜杠（`C:\Dir\\\\Sub\File` → `C:\Dir\Sub\File`）
- 大小写转换（Windows 环境下不区分大小写）
- 相对路径处理（`.` 和 `..` 的智能解析）

### 2. 虚拟路径解析
- 中文虚拟路径支持（"桌面"、"下载"、"我的文档"等）
- 自动映射到系统实际路径
- 跨平台兼容性

### 3. 环境变量展开
- 支持 Windows 环境变量（`%USERPROFILE%`、`%TEMP%` 等）
- 自动展开为实际路径
- 错误处理和回退机制

### 4. 路径验证
- 非法字符检测（`< > : " | ? *`）
- 路径长度验证
- 格式正确性检查

### 5. 快捷方式解析
- Windows `.lnk` 文件解析
- 自动获取目标路径
- 错误处理和回退

## 使用示例

### 基本路径解析
```c
// 解析虚拟路径
PathInfo *info = path_resolve("桌面\\文档.txt", NULL);
if (info && info->is_valid) {
    printf("绝对路径: %s\n", info->absolute_path);
    printf("规范化路径: %s\n", info->normalized_path);
}
path_info_free(info);
```

### 文件操作集成
```c
// 复制文件（支持虚拟路径）
bool success = file_ops_copy("桌面\\重要文件.txt");
if (success) {
    printf("文件已复制到剪贴板\n");
}
```

### 路径验证
```c
// 验证路径合法性
PathError error;
if (path_validate("C:\\Test\\file.txt", &error)) {
    printf("路径有效\n");
} else {
    printf("路径无效: %s\n", path_get_error_string(error));
}
```

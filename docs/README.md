## 🚀 快速开始

### 1. 环境准备
确保您的开发环境已安装：
- C编译器 (GCC/Clang)
- SDL3库
- CMake构建系统

### 2. 项目构建
```bash
cd FileScope
mkdir build && cd build
cmake ..
make
```

### 3. 运行示例
```bash
./FileScope
```
